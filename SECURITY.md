# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by contacting:
- Email: tribbrix23@gmail.com
- Facebook: John David L. Perez

Please include the following information in your report:
- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Suggested fix (if any)

## Response Timeline

We aim to respond to security reports within 48 hours and will work with you to verify and address the issue promptly.

## Safe Harbor

We support safe harbor for security researchers following responsible disclosure practices.
